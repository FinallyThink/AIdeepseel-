# 网易云音乐点歌

## 观众点歌

同一直播间有送礼记录的观众，发送以下弹幕：

```text
点歌 歌名
点歌 歌名 / 歌手
点歌 5276808
点歌 https://music.163.com/#/song?id=5276808
```

歌曲按请求先后排队。没有准确歌名匹配时提示补充歌手或直接使用歌曲 ID，不自动用翻唱或其他相似歌名替代。搜索歌名的歧义可在管理端搜索确认 ID 后点播。

资格按采集器提供的稳定 User.Id 记录，不按昵称授予。昵称相同但 ID 不同不能冒用；没有用户 ID 时提示无法核验。任意有效礼物均可解锁，不按歌扣除资格。每位观众同时一首待播/在播歌曲，间隔 30 秒；总队列最多 20 首，含失败待管理的歌曲。

资格与队列保存在应用用户数据目录的 music.json，重启保留；实机和演练分开。旧版已有的待回复礼物、已播礼物历史和长期记忆档案可补充资格，前提是这些记录有用户 ID。按 RoomId/WebRoomId 匹配直播间；采集器无稳定 WebRoomId 时，开播场次变化可能无法自动关联旧资格。

## 管理端

侧边栏新增“网易云点歌”。可搜索歌曲、加入管理端试播、查看点歌队列和反馈、暂停/继续、结束当前歌曲、移除待播歌曲和重试失败项。管理端试播不要求观众送礼资格。

“开启点歌”控制是否接受新请求和开播，不会自动停止已经播放的歌；要立即停止可点击“结束当前歌曲”。整体“暂停互动”停止新的歌曲和回复开播，当前声音继续完成。歌曲单独暂停不影响主播回复。

在工作台加入演练消息、进入 demo 房间后，可在点歌页点击“演练送礼点歌”，模拟一位观众送小心心并请求歌曲 ID 5276808。演练使用固定 AI 回复，但网易云搜索和音频播放需要联网。

## 播放规则

展示端播放歌曲，工作台预览不发声。歌曲作为背景音乐，与主播语音独立播放；弹幕回复、礼物感谢、关注感谢和进场欢迎都无需等待歌曲结束。主播语音开始缓冲或播放时，背景音乐降至设定音量的 25%，说完或播放失败后恢复。礼物仍在语音队列内优先，语音之间不会重叠。点歌指令不进入普通 AI 候选池，歌曲播放也不扣饭量。

展示端左侧显示当前歌曲、歌手、点歌观众、播放时间和下一首。直播伴侣仍需采集展示窗口及对应音频设备。

## 网易云接口与范围

使用网易云官方域名的搜索、歌曲详情、实际播放地址接口和 music.126.net 音频 CDN。当前无需额外服务器、不保存账号 Cookie。只播放平台实际返回的完整可播地址，不绕过会员或付费限制；无地址或试听歌曲显示失败原因并保留队列项，可换歌或重试。

这些网页接口并非稳定性承诺的官方开放 SDK，可能因平台变更、地区、网络或曲目权限而不可用。搜索得到歌曲不代表一定可完整播放。播放地址过期后重新获取，不把短期直链作为永久资源保存。音频经主进程受限流式转发到展示端，不下载保存到歌曲库。

## 验证

`npm test` 覆盖资格隔离、昵称冒用、冷却时间、队列、源地址校验、会员/试听处理、音乐与语音同时播放及背景音量计算。`npm run smoke` 不调用真实音乐网络接口；`npm run smoke:music` 另联网请求一首实际可播歌曲，检查展示端真实开始、暂停、继续、切歌、说话时音乐降低及恢复音量，并保存 music-display.png/music-manager.png。

联网自检会播放几秒音乐，不会调用付费 AI。请在正式直播前运行。
