# 澜鲸 · 独立直播程序

技术栈：Electron + React + JavaScript。展示端和管理端分离，复制使用澜鲸素材，不需要启动桌面助手。当前为立绘姿态切换与轻微呼吸动画，不是绑定的 Live2D 模型。

## 启动与演练

双击项目根目录 `start-studio.cmd` 或 `start.cmd`。命令行：`npm start`。会先构建 React，再打开工作台和展示窗口。当前依赖已经安装；换机器使用 `npm install` 安装，要求 Node.js 22+。

首次点击工作台“加入演练消息”，会进入明确标注的离线模式，加入两条弹幕和一条礼物。再点“开始互动”，使用固定回复和真实 Windows TTS，不调用付费 AI。到“回复队列”查看过程。实机模式和演练模式需暂停、处理完队列再切换。

## 实机配置

新增网易云音乐点歌：同直播间送过礼物的观众可通过“点歌 歌名 / 歌手”或歌曲 ID 请求歌曲，管理端“网易云点歌”可管理队列及试播。完整说明见 `docs/MUSIC.md`。

在参数设置中保存 DeepSeek Key，或主动点击“从桌面助手导入”。不会在启动时自动读取助手密钥。也支持 DEEPSEEK_API_KEY 环境变量。密钥在主进程使用 safeStorage 加密保存，不进入展示端。

AI 请求官方 https://api.deepseek.com/chat/completions，支持 deepseek-flash 与 deepseek-v4-pro。先从候选弹幕中选取一条，再结合已播上下文生成回答。真实观众消息会发送给该服务。当前真实付费 AI 请求与抖音数据尚未联调；离线固定回复和系统语音播放已经实测。

采集器已经下载并配置，详见 `tools/COLLECTOR-SETUP.md`。首次运行会信任 HTTPS 解密根证书，先前授权未完成，因此目前没有启动它。新程序不安装根证书、不自动修改系统代理或伴侣文件。在管理端连接采集器后，选择发现的 RoomId/WebRoomId，再开始互动。

直播伴侣窗口采集“澜鲸 · 直播展示”，同时采集桌面/对应音频设备的声音。管理端预览不播放声音，只有展示窗口负责音频。推荐展示窗口 16:9 或全屏。

## 消息处理规则

- 普通消息进入最多 100 条的候选池，超龄丢弃。AI 每个选评周期最多选择一条适合回应的消息，不机械回复全部弹幕。
- 普通回复最多 5 条，计入排队、生成、语音就绪、播放以及失败待重试消息。容量满时等待，不继续入列。
- 礼物直接进入优先队列，不受 5 条限制，暂停期间也会保存。礼物不因超龄或队列满丢弃；AI 失败或未提供合格感谢祝福时使用包含昵称、数量、礼物与祝福的保底文案。语音和播放失败仍保留，管理端可重试，无法直接删除礼物。
- 完整流程：选取 → 入列 → 生成文字 → 合成完整 WAV → 展示窗口加载 → **实际音频 playing 事件** → 更新字幕和左侧上下文 → 播放结束出列。不是逐字流式语音，也不是字级口型同步。
- 同时只播放一条，可后台准备下一条。新礼物优先于尚未播放的普通回复，不打断已开始的语音。
- 暂停保留全部队列，停止新选评及新播报；当前音频继续完成，生成中的任务可完成到待播状态。
- 队列和最近 60 条上下文持久保存。重启后未生成完的任务重新准备；退出时播放状态不确定的消息标为失败，需要确认后手动重试，避免自动重复感谢。
- 去重仅针对已经收到的数据。断线期间是否补发由采集器决定；磁盘故障会报错，不能保证断电/磁盘故障下绝对不丢消息。

## 可调参数

新增“小鲸的补给站”：展示端在左侧聊天面板下方以独立状态条显示剩余饭量和开心值，不覆盖人物立绘；礼物按价值增加两项，每次成功播完回复扣 1 饭量，并显示增减动画。初始值可在管理端设置，完整规则与初始人设见 `docs/PERSONA.md`。

模型、人设、选评间隔、回复字数、候选有效期、Windows 系统音色、语速、音量、标题、副标题、背景主题、自定义背景图、人物大小、上下文条数与开关。普通容量 5 和礼物优先规则固定。内置深海蓝、暮紫和纯绿主题。

音色支持 **阳光少女 · AMD GPU**、**知心大姐姐 · AMD GPU**，并保留 Windows 系统音色。在“参数设置 → 直播音色（GPU / 系统）”选择并保存。两个 GPU 音色共享本机 `E:/codex/live2d形象` 的 GPT-SoVITS / DirectML 运行时和模型，不需要运行桌面助手，也不重复复制大型模型。可通过环境变量 `LANJING_TTS_ROOT` 指定迁移后的资源根目录；需保留原有 runtime/voices 目录结构。

GPU 模型按需加载，同音色后续请求复用进程，切换音色时关闭旧进程释放显存；切回系统音色时也释放 GPU。首次生成约需十几秒，以实际文本和显卡为准。GPU 失败会保留任务并报错，不会静默换成系统声音。音量由展示窗口控制，语速在合成阶段生效。生成 WAV 前不会播放，依旧在实际开始播放时同步显示字幕。

本机两个音色的实际合成验证：`node scripts/verify-gpu-voices.cjs`。样音和结果保存在 `artifacts/voice-tests/`。GPU 语音的展示端同步自检可设置 `LANJING_SMOKE_VOICE=gpt-sovits:sunshine-girl` 后运行 `npm run smoke`；不调用付费 AI，但会真实播放语音。

## 本机存储

新增跨直播长期记忆：详见 `docs/MEMORY.md`。项目 `memory/` 保存手工笔记、完整已播聊天档案和增量摘要，管理端“长期记忆”可查看和编辑。每次选评/回复默认额外引用最多 6000 字相关记忆，不改变最近 10 轮/6 轮的规则。

配置、加密密钥、队列、临时音频保存在 Electron 用户数据目录，默认 `%APPDATA%/lanjing-live-studio/`（以 Electron 实际 app name 为准）。播放完成清理音频；异常退出可能留存临时文件。背景图复制到该目录，角色素材独立位于本项目 public/character。

关闭管理端退出程序；关闭展示端会保留队列，播放不确定的任务需重试。管理端使用受控 IPC，展示端使用 sandbox、contextIsolation 和 CSP，不暴露 Node.js 或 API 密钥。

## 验证

`npm test` 验证队列、恢复、AI ID 校验、礼物保底祝福和原有协议；`npm run build` 构建；`npm run smoke` 使用隔离 `.smoke-profile` 打开双窗口，真实合成并播放系统音频，不调用付费 AI，检查工作台、设置和队列页面，输出截图及 `artifacts/smoke.json`。不要在正式直播时运行语音自检，以免声音进入直播。

## 游戏场景解说 API

用于外部脚本定时读取游戏状态后，将场景信息交给 AI，让直播姬生成解说并通过现有语音队列播放。接口接收脚本提供的文本，不会自动截图或读取游戏。

启动工作台后，向 `http://127.0.0.1:17861/api/scene` 发送 JSON POST，请求头为 `Content-Type: application/json`。仅允许本机程序调用，不支持网页跨域调用。

```json
{
  "game": "宝可梦",
  "scene": "进入常青森林，队伍血量偏低，刚遇到野生皮卡丘",
  "instruction": "用轻松的口吻解说两句，给出下一步建议"
}
```

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `scene` | 是 | 当前场景、事件或游戏状态，非空字符串，最多 2000 字符 |
| `game` | 否 | 游戏名称，最多 100 字符 |
| `instruction` | 否 | 解说口吻、重点等要求，最多 500 字符；默认简短表达感受或给出下一步建议 |

场景接口自动使用 AI 生成模式，无需传入 `mode` 或 `text`。如需逐字朗读固定台词，使用原有 `/api/speak` 的 `say` 模式。

### PowerShell 调用示例

```powershell
$body = @{
  game = '宝可梦'
  scene = '进入常青森林，队伍血量偏低，刚遇到野生皮卡丘'
  instruction = '用轻松的口吻解说两句，给出下一步建议'
} | ConvertTo-Json
Invoke-RestMethod -Uri 'http://127.0.0.1:17861/api/scene' `
  -Method Post -ContentType 'application/json; charset=utf-8' `
  -Body ([Text.Encoding]::UTF8.GetBytes($body))
```

脚本可在每次读取游戏状态后执行上述请求，建议每 15–30 秒或场景发生变化时提交。`scene` 尽量写明当前位置、血量、目标和刚发生的事件，让 AI 有依据地解说。

### 返回值与播放规则

成功返回 HTTP `202`，例如：

```json
{"id":"任务ID","state":"queued","running":true}
```

`id` 是语音队列任务 ID；`state` 是当前任务状态；`running` 表示互动是否开启。`202` 仅表示已加入队列，不代表 AI 已生成或语音已播放。需配置 AI 和语音、开启“开始互动”并保持展示端开启，才能生成和播放；暂停时仍可提交。

定时上报的新场景会替换尚未开始准备的旧场景任务，避免陈旧场景积压；已开始生成或播放的任务会继续完成。场景提交不会更新参数设置中的直播主题或活动。

错误状态：`400` 参数或 JSON 无效；`403` 网页来源请求被拒绝；`413` 请求超过 16KB；`429` 本机 API 队列达到 100 条上限；`503` 程序正在关闭。遇到 `429` 应降低上报频率、等待队列消化后再提交。
