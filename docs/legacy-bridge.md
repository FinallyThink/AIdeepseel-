# 直播 AI

本机 Node.js 程序，把抖音弹幕和礼物交给现有“桌面助理”生成回复、动作和语音。无需 npm 安装依赖，要求 Node.js 22 或更新版本。

## 当前完成与限制

已实现采集器 WebSocket 接入、断线重连、房间发现与筛选、消息去重、礼物增量合并、礼物优先、有界队列、过期弹幕丢弃、暂停及桌面助理 HTTP 对接。所有回复通过助手 `/v1/chat` 生成并朗读，因此需要桌面助理已经配置 DeepSeek 和语音。

**本项目不包含抖音底层采集器，也不会仅靠启动本程序就读取直播伴侣。** 第一次使用需另外准备兼容采集器。当前机器发现直播伴侣安装于 `E:/webcast_mate`，桌面助理源码位于 `E:/codex/live2d形象`。真实直播采集和真实助手播报尚未联调；测试使用本机模拟助手，不消耗 API 额度。

## 直播伴侣接入

1. 启动“桌面助理”，在其设置中配置 DeepSeek 和语音，确保本机 API 已启动。
2. 准备 [DouyinBarrageGrab 发布版](https://gitee.com/haodong108/dy-barrage-grab/releases)，先阅读其[官方说明](https://github.com/ape-byte/DouyinBarrageGrab)。本项目根据其[消息实体源码](https://github.com/ape-byte/DouyinBarrageGrab/blob/main/BarrageGrab/Modles/JsonEntity/BarrageMessages.cs)接收 `Type=1` 弹幕和 `Type=5` 礼物，`Data` 可为 JSON 字符串或对象。
3. 在采集器配置中将 `wsListenPort` 设为 `8888`、`listenAny` 设为 `false`、`pushFilter` 设为 `1,5`。直播伴侣的采集方式、所需权限及版本兼容性以采集器文档为准。采集器可能涉及代理、证书或伴侣文件修改；本项目没有自动安装或修改这些设置。当前已安装的伴侣版本是否兼容仍需实际检查。
4. 先按采集器文档启动采集器，再启动直播伴侣开播，确认采集器能显示弹幕与礼物。
5. 双击 `start.cmd`。看到“发现直播间”后，输入 `room 实际房间ID`，再输入 `check` 检查桌面助理，最后输入 `start` 开启自动回复。
6. 观众发弹幕或送礼后，本程序调用桌面助理；助手的声音通过直播伴侣桌面音频采集传入直播。请在伴侣中确认对应音频设备已加入直播。

默认处于暂停状态；没有选择房间时不能自动回复，避免同时打开其他直播间时串台。可在 config.json 预先设置 `roomId`，支持采集器的 `RoomId` 或 `WebRoomId`。RoomId 可能随开播场次变化；首次应根据实际采集消息选择。

## 操作

- `status`：连接、最后收到数据时间、房间、队列、成功/跳过/失败数量。
- `rooms`：本次运行发现的房间。
- `room <ID>`：选择房间、暂停并清空队列，再输入 `start` 恢复。
- `start` / `pause`：开启或暂停，暂停清空未提交队列，已提交的语音继续完成。
- `check`：检查桌面助理健康接口。
- `quit`：停止采集，等待已提交的回复完成后退出。

双击 `demo.cmd` 可离线演示礼物优先和弹幕处理，**不会产生 AI 回复或语音，也不会连接真实采集器**。输入 `quit` 退出。

配置写在 `config.json`，修改后重启。`tokenFile` 默认读取 `%APPDATA%/deepseek-desktop-pet/api-token.txt`，令牌不写入本项目、不输出到日志。`blockedWords` 可填不希望播报的词。`minIntervalMs` 是上一条回复完成后的最短间隔；桌面助理的 `/v1/chat` 会等语音播放完成再返回。每次只提交一条，避免堆积在助手内部。

礼物使用采集器的增量 `GiftCount`，不是累计 `RepeatCount`；同房间、同观众、同礼物的待播消息合并。队列满时礼物可替换待播弹幕；全是礼物时仍可能丢弃新消息，并计入跳过数量。断线期间的数据能否补发由采集器决定，本程序不承诺零丢失。请求失败或超时后不自动重播，以免重复感谢；可用 `status` 查看失败。真实弹幕发送给现有桌面助理使用的 AI 服务，并进入该助手现有对话历史。

## 验证

运行 `npm test`。覆盖大整数 ID、字符串 Data、房间与主播过滤、去重、礼物增量合并及优先级、过期丢弃、失败不重放、串行处理和真实本机 HTTP 鉴权契约。

## 后续真实联调

仍需准备采集器、确认当前直播伴侣兼容、启动桌面助理、实际开播并分别发送一条弹幕和一个礼物，检查助手回复及直播收音。只有这些验证完成后才能确认整条真实直播链路可用。
